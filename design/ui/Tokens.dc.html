4. 결과 화면 포커스 순서 · 읽기 라벨

  1. 처음 화면으로 — 아이콘 버튼
  2. 기록
  3. 문제 듣기 — 제목 (heading)
  4. 재생 위치 — 조절 막대, 값 “5초 / 12초”
  5. 5초 전
  6. 재생 / 일시정지 — 화면이 열리면 여기로 포커스 이동
  7. 처음부터
  8. 0.75배속 · 1배속 · 1.25배속 — 선택됨 상태 포함
  9. 시제품 안내 — 글
  10. 읽어 주는 문장 — 전체 문장을 한 번에 읽음
  11. 원본 사진 — 이미지 라벨 + 크게 보기
  12. 읽은 문제 — 라벨은 읽어 주는 문장과 같게 (수식을 기호 이름으로 읽지 않음)
  13. 다시 찍기
  14. 기록에 저장 — 토글, “저장됨”
  15. 새 문제

5. 화면 읽기 기능 · 큰 글자

  • 처리 단계가 바뀔 때만 한 번 알림 (announceForAccessibility). 경과 시간은 읽지 않음
  • 결과가 나오면 “문제를 다 읽었어요. 재생 버튼” 알림 후 재생 버튼에 포커스. 자동 재생하지 않음 (화면 읽기 음성과 겹침)
  • 하이라이트는 눈으로 보는 사람용. 재생 중 live region을 쓰지 않아 두 목소리가 겹치지 않게
  • 오류·오프라인 배너는 role="alert", 안내는 role="status"
  • 음성 사용 불가일 때도 읽어 주는 문장은 그대로 보여서 화면 읽기 기능으로 들을 수 있음
  • 요청 제한 카운트다운은 시작과 끝에만 알림
  • allowFontScaling 켬, 높이는 최소값만. 200%에서 재생 버튼은 한 줄 전체, 5초 전·처음부터는 두 칸, 버튼 줄은 flexWrap
  • 잘림은 기록 행 첫 줄(최대 2줄)에만. 나머지 글은 모두 줄바꿈
  • 자르기 화면은 ‘사진 전체 쓰기’로 끌기 없이도 진행 가능
  • 다크 모드는 시스템 설정을 따름 (useColorScheme)
